# 🏎️ Assistente Inteligente de Upgrades de Carro

Um script em Python que usa IA (Gemini API) para analisar modificações de carro e gerar relatórios técnicos.

## 📋 Funcionalidades

- ✅ Leitura de dados via Pandas (CSV)
- ✅ Integração com IA (Google Gemini)
- ✅ Loops e estruturas de dados (Aula 02-03)
- ✅ Funções e lógica condicional (Aula 01)
- ✅ Escrita/leitura de arquivos (Aula 04)
- ✅ Menu interativo
- ✅ Filtros e buscas
- ✅ Relatório em HTML

## 🚀 Como usar

### Requisitos
```bash
pip install pandas google-genai
```

### Executar
```bash
python main.py
```

### Menu de opções
1. **Analisar peças com IA** - Gera análises completas de cada peça
2. **Ver análises anteriores** - Mostra análises do CSV salvo
3. **Filtrar por categoria** - Busca peças por tipo (Motor, Suspensão, etc)
4. **Filtrar por complexidade** - Busca peças por nível de dificuldade
5. **Sair** - Encerra o programa

## 📁 Arquivos gerados

- `resultados_upgrades.csv` - Tabela com todas as análises
- `relatorio.html` - Relatório visual em HTML

## 🛠️ Tecnologias

- **Python 3.x**
- **Pandas** - Manipulação de dados
